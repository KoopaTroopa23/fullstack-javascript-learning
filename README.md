Learning repository for mastering full-stack JavaScript development.

This repository documents my structured journey learning **modern full-stack JavaScript development**.

The project is organized into multiple sections covering **JavaScript fundamentals, backend development, and frontend frameworks**.

## Root Project

The root of this repository contains a separate JavaScript/Node project in addition to the subfolders below.

This repository is organized as a multi-project workspace, with different folders covering JavaScript fundamentals, backend development, and React frontend practice.

## JavaScript Fundamentals

`javascript-course/`

Core JavaScript concepts and exercises used to build a strong programming foundation.

Topics include:

* JavaScript fundamentals
* Functions
* Conditional logic (if/else)
* Boolean logic
* Truthy and falsy values
* Type coercion
* Arrays and array methods
* Objects
* Loops
* Debugging techniques

These files are **numbered in learning order** to demonstrate structured progression.

---

## Node Backend Basics

`node-backend-basics/`

A beginner-friendly **Node.js backend project** built with Express demonstrating core backend development concepts.

Features include:

* Node.js backend fundamentals
* Express.js framework usage
* REST API design
* Handling JSON requests and responses
* In-memory data storage
* Basic CRUD operations

---

## React Frontend
