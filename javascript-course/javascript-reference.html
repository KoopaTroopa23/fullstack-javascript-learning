JavaScript Master Reference

Keep this open while learning — quick reference for operators + built-ins.

Big Picture

HTML → DOM → JavaScript → Updates UI

DOM = live object representation of your HTML page that JavaScript can read and change.
When you click a button, the browser triggers a click event, and JavaScript runs the function attached to that event, which updates the DOM.

*   // multiplication
/   // division
%   // remainder (modulus)
**  // power (exponent)

Increment / Decrement

Comparison Operators

==   // equal value (loose)
===  // equal value + type (STRICT — USE THIS)
!=   // not equal
!==  // strict not equal
>    // greater than
<    // less than
>=   // greater or equal
<=   // less or equal

5 == "5"   // true  (bad)
5 === "5"  // false (good)

Logical Operators

&&  // AND (both true)
||  // OR (one true)

Dot Notation (.) vs Bracket Notation ([ ])

// Dot notation = object.property
const user = { name: "Kevin", age: 45 };

user.name       // "Kevin"
user.age        // 45

// Bracket notation = object["property"]
user["name"]    // "Kevin"
user["age"]     // 45

// Bracket notation is required when the key is stored in a variable:
const key = "name";
user[key]       // "Kevin"
