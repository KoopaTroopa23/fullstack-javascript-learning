/*
====================================================
Web Development Reference Notes
====================================================
*/

/*
----------------------------------------------------
Technologies
----------------------------------------------------
JavaScript  -> Language            -> Core skill
React       -> UI library          -> Build interfaces
Angular     -> Frontend framework  -> Structured frontend apps
Node.js     -> Runtime             -> Runs JS on server
Next.js     -> Fullstack framework -> React + backend together
*/

/*
----------------------------------------------------
HTTP & APIs
----------------------------------------------------
HTTP Request:
Browser asks a server for something (page, data, login, etc.)

API:
A set of server endpoints the frontend communicates with

Endpoint Examples:
GET    /users
POST   /login
PUT    /users/1
DELETE /users/1
*/

/*
----------------------------------------------------
CRUD Operations
----------------------------------------------------
Create  -> POST   -> Add new data
Read    -> GET    -> Retrieve data
Update  -> PUT/PATCH -> Modify data
Delete  -> DELETE -> Remove data
*/

/*
----------------------------------------------------
Async (Asynchronous Programming)
----------------------------------------------------
Code continues running while waiting for data.

Used for:
- API requests
- Database queries
- Timers
- File loading

Behavior:
Page loads -> user can interact -> data arrives later
*/

/*
----------------------------------------------------
State
----------------------------------------------------
The data your UI currently remembers.

Examples:
- Logged in user
- Form input text
- Counter value
- Shopping cart items

When state changes -> UI updates
*/

/*
----------------------------------------------------
Data Flow
----------------------------------------------------
User -> Frontend -> API -> Server -> Database
User <- Frontend <- API <- Server <- Response
*/

/*
----------------------------------------------------
Debugging
----------------------------------------------------
Finding where program behavior differs from expectation.

Tools:
- console.log()
- breakpoints
- stepping through code

Goal:
Locate incorrect logic and fix it
*/
